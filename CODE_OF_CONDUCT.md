# 行为准则 · Code of Conduct

## 我们的承诺 · Our pledge

我们希望每个人都能在这里自在地参与，无论年龄、体型、残障、族裔、性别认同与表达、经验水平、教育程度、
社会经济地位、国籍、外貌、种族、宗教或性取向。

We pledge to make participation in this project a harassment-free experience for everyone,
regardless of age, body size, disability, ethnicity, gender identity and expression, level of
experience, education, socio-economic status, nationality, personal appearance, race, religion,
or sexual identity and orientation.

## 我们期待的行为 · Expected behaviour

- 友善、耐心，尊重不同的观点和经验。Be kind and patient; respect differing views and experience.
- 给出和接受建设性的意见，对事不对人。Give and accept constructive feedback about the work, not the person.
- 犯错时承认并改正。Own mistakes and fix them.
- 关注对社区整体最好的做法。Focus on what is best for the community.

## 不可接受的行为 · Unacceptable behaviour

- 骚扰、侮辱、人身攻击，带有性意味的言语或关注。Harassment, insults, personal attacks, sexualised language or attention.
- 公开或私下泄露他人隐私（包括聊天记录、账号、联系方式）。Publishing others' private information, including chat logs or accounts.
- 利用本项目冒充真人欺骗他人，或用于骚扰、诈骗、刷屏。Using this project to deceive people into thinking a bot is human, or for harassment, fraud or spam.
- 其他在专业场合明显不恰当的行为。Other conduct that would be inappropriate in a professional setting.

## 适用范围与执行 · Scope and enforcement

本准则适用于本项目的所有空间（issue、PR、讨论区），以及代表本项目的公开场合。
This code applies in all project spaces and when representing the project in public.

遇到问题请通过 GitHub 的私密报告联系维护者（仓库 **Security → Report a vulnerability**，标题注明
"行为准则 / Code of Conduct"），或在 issue 中 @ztm-njau 请求私下联系。维护者会保密处理，并可视情况采取
提醒、警告、临时或永久禁止参与等措施。

Report problems privately to the maintainers through GitHub (**Security → Report a vulnerability**,
titled "Code of Conduct"), or mention @ztm-njau in an issue to ask for a private channel. Reports are
handled confidentially; maintainers may respond with a note, a warning, or a temporary or permanent ban.
